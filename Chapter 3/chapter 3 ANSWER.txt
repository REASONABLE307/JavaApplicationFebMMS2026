3.10 Compare and contrast the if single-selection statement and the while repetition statement. How are these two statements similar? How are they different?

Similarities:

Both are control statements used to control the flow of a program.
Both use a condition that evaluates to either true or false.
Both can execute a block of code depending on a condition.

Differences:

The if statement executes its block of code only once if the condition is true.
The while statement repeatedly executes its block of code as long as the condition remains true.
The if statement does not repeat the execution of its block, while the while statement performs repetition.
3.11 Explain what happens when a Java program attempts to divide one integer by another. What happens to the fractional part of the calculation? How can you avoid that outcome?

When one integer is divided by another integer in Java, the result is an integer. The fractional part of the result is discarded; it is not rounded.

3.12 Describe the two ways in which control statements can be combined.

Control statements can be combined in two ways:

Control-statement stacking: Placing control statements one after another in a sequence.
Control-statement nesting: Placing one control statement inside another control statement.

Example of nesting:

if (age >= 18) {
    if (age <= 60) {
        System.out.println("Eligible");
    }
}

Here, one if statement is nested inside another if statement.

3.13 What type of repetition would be appropriate for calculating the sum of the first 100 positive integers? What type would be appropriate for calculating the sum of an arbitrary number of positive integers? Briefly describe how each of these tasks could be performed.

(a) Sum of the first 100 positive integers

A counter-controlled repetition is appropriate because the number of repetitions is known in advance. A for loop can be used to add the numbers from 1 to 100.

Example:

int sum = 0;

for (int i = 1; i <= 100; i++) {
    sum += i;
}

System.out.println(sum);

Output:

5050

(b) Sum of an arbitrary number of positive integers

A sentinel-controlled repetition is appropriate when the number of integers is not known in advance. The program can continue accepting numbers until the user enters a special value, called a sentinel, to indicate that input should stop.

For example, the sentinel could be -1, provided negative numbers are not valid inputs.

3.14 What is the difference between preincrementing and postincrementing a variable?

Preincrement (++x): Increments the variable by 1 before its value is used in an expression.

Postincrement (x++): Uses the variable's current value in the expression before incrementing it by 1.

Example:

int x = 5;
int a = ++x;

Here, x becomes 6, and a is assigned 6.

int y = 5;
int b = y++;

Here, b is assigned 5, and then y becomes 6.

In summary: Preincrement increments before the value is used, while postincrement increments after the current value is used.

3.15 Identify and correct the errors in each of the following pieces of code.
(a) Original code
if (age >= 65);
System.out.println("Age is greater than or equal to 65");
else System.out.println("Age is less than 65);

Errors:

There is an unnecessary semicolon (;) after the if condition.
The second println statement has a missing closing quotation mark.

Corrected code:

if (age >= 65)
    System.out.println("Age is greater than or equal to 65");
else
    System.out.println("Age is less than 65");
(b) Original code
int x = 1, total;
while (x <= 10) {
    total += x;
    ++x;
}

Error:

The variable total is not initialized before it is used.

Corrected code:

int x = 1, total = 0;

while (x <= 10) {
    total += x;
    ++x;
}
(c) Original code
while (x <= 100)

total += x;
++x;

Error:

The loop body is missing braces. Without braces, only total += x; belongs to the loop, so x is never incremented inside the loop. If x <= 100 is initially true, the loop may continue indefinitely.

Corrected code:

while (x <= 100) {
    total += x;
    ++x;
}

Note: The variables x and total must be declared and initialized appropriately before this loop.

(d) Original code
while (y > 0) {
    System.out.println(y);
    ++y;
}

Error:

The variable y is incremented instead of decremented. If y starts with a positive value, the condition y > 0 remains true, causing an infinite loop.

Corrected code:

while (y > 0) {
    System.out.println(y);
    --y;
}

Note: The variable y must be initialized to a positive integer before the loop.
