2.2 True or False

a) Comments cause the computer to print the text after the // on the screen when the program executes.

Answer: False. Comments are ignored by the compiler and are not displayed when the program executes.

b) All variables must be given a type when they’re declared.

Answer: True. In Java, variables must have a declared type, such as int, double, or String.

c) Java considers the variables number and NuMbEr to be identical.

Answer: False. Java is case-sensitive, so number and NuMbEr are different variables.

d) The remainder operator (%) can be used only with integer operands.

Answer: False. The remainder operator can be used with both integer and floating-point operands in Java.

e) The arithmetic operators *, /, %, +, and - all have the same level of precedence.

Answer: False. The operators *, /, and % have higher precedence than + and -.

2.4 Identify and Correct the Errors
a) Incorrect statement
if (c < 7); System.out.println("c is less than 7");

Error: The semicolon (;) immediately after the if condition terminates the if statement.

Correct statement:

if (c < 7)
    System.out.println("c is less than 7");
b) Incorrect statement
if (c => 7) System.out.println("c is equal to or greater than 7");

Error: The operator => is invalid in Java. The correct operator is >=.

Correct statement:

if (c >= 7)
    System.out.println("c is equal to or greater than 7");

import java.util.Scanner;

public class Product {
    public static void main(String[] args) {

        // This program calculates the product of three integers.

        Scanner input = new Scanner(System.in);

        int x, y, z, result;

        System.out.print("Enter first integer: ");
        x = input.nextInt();

        System.out.print("Enter second integer: ");
        y = input.nextInt();

        System.out.print("Enter third integer: ");

        System.out.printf("Product is %d%n", result);

        input.close();
    }

2.9 True or False

a) Java operators are evaluated from left to right.

Answer: False. Operators are evaluated according to precedence and associativity. For operators with the same precedence, most arithmetic operators are evaluated from left to right.

b) The following are all valid variable names: _under_bar_, m928134, t5, j7, her_sales$, his_$account_total, a, b$, c, z and z2.

Answer: True. All these names are valid Java identifiers, although identifiers consisting of only underscores are not permitted in modern Java. Since _under_bar_ contains other characters, it is valid.

c) A valid Java arithmetic expression with no parentheses is evaluated from left to right.

Answer: False. Java evaluates expressions according to operator precedence first. Operators with the same precedence are generally evaluated from left to right.

d) The following are all invalid variable names: 3g, 87, 67h2, h22 and 2h.

Answer: False. h22 is a valid variable name because it begins with a letter. The others are invalid because they begin with digits.
