Exercise 5.12 – Random Integers
Use Math.random() to generate random integers.

General formula:
n = minimum + (int)(Math.random() * range);


Solutions:
// a) 1 <= n <= 2
n = 1 + (int)(Math.random() * 2);

// b) 1 <= n <= 100
n = 1 + (int)(Math.random() * 100);

// c) 0 <= n <= 9
n = (int)(Math.random() * 10);

// d) 1000 <= n <= 1112
n = 1000 + (int)(Math.random() * 113);

// e) -1 <= n <= 1
n = -1 + (int)(Math.random() * 3);

// f) -3 <= n <= 11
n = -3 + (int)(Math.random() * 15);
